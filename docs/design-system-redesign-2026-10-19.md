## 设计与实现决定

- 采用 Ant Design 6.6.6 的完整预设和真实组件。排版、尺寸、间距、圆角、层级及动效以官方算法为基础，不再维护一套模拟组件库。
- `theme/cohesion-theme.json` 记录定制，`theme/create-theme.mjs` 组合官方浅色、深色、紧凑算法与必要的可读性修正。ConfigProvider 和导出器调用同一主题工厂。
- Logo 色服务品牌识别，UI 主操作色服务可读性和状态。成功、信息、警告、错误保留独立的功能语义。
- 信息结构统一为概览、色彩、排版、布局、组件、场景模式、动效与工程接入。桌面持久导航，手机使用抽屉导航，提供跨页搜索和全局主题、密度及动效控制。
- 真实组件分为操作、输入、导航、反馈、数据五类；场景提供内容管理、资料偏好及移动服务。搜索、筛选、新建、发布、校验和预约均有本地演示状态。
- 品牌 Orb / Beam 收在按需展开的品牌实验中。普通组件采用官方 100 / 200 / 300ms 时长与缓动，减少动效同时控制主题过渡、CSS 循环及 Canvas 实验。
- React、ReactDOM、Ant Design 与图标版本锁定，esbuild 预编译；运行时不依赖 CDN、浏览器 Babel 或 Tailwind Play CDN。

## 已修复的混淆与缺陷

| 问题 | 修复 |
| --- | --- |
| 自定义值、官方默认、预览与分发各自维护 | 正式配置与共用主题工厂生成四模式快照，标记官方原值和定制差异 |
| 深色品牌色直接用于白字按钮，状态前景不匹配 | 深色主按钮使用深色前景；统一算法核查按钮、语义正文、占位符与主色浅填充 |
| 紧凑派生值被误判为独立品牌定制 | 对照表同步采用当前官方模式与紧凑算法 |
| 动效配置关闭后加载图标和骨架仍持续循环 | 全局动效状态同时暂停 CSS 循环，保留文字和结果状态 |
| 移动端动效说明表格撑出页面 | 移除错误套用的普通宽表样式，保留内容换行 |
| 手机搜索图标因泛化 span 选择器被隐藏 | 隐藏具名文本，保留搜索图标与可访问名称 |
| 邮箱原生校验拦截 Ant Design Form 错误提示 | 表单采用统一组件校验，错误就近显示 |
| 抽屉关闭后焦点丢失 | 在关闭完成时归还触发控件，导航完成时归还主要内容 |
| “产品模式”与导航“场景模式”混用 | 统一页面、导航和浏览器标题 |
| 历史 v1.1 审查结论被误认为当前接入规则 | 旧审查明确标记历史范围，当前以 README 与 DESIGN 为准 |

## 可复现校验

```sh
node scripts/generate-antd-tokens.mjs --check
pnpm check
pnpm serve --port 8766
```

主题检查覆盖 536 个 token × 4 种模式、408 组包含透明度合成的对比度配对、减少动效、CSS 变量引用及分发镜像。它验证指定的配对，不代表整套组件或站点通过完整 WCAG 认证。

Chromium 浏览器最终验证覆盖 56 组视口、主题与密度组合，包括 320、375、1264、1440 CSS px 的代表场景；整页横向溢出为 0。27 项交互检查全部通过，控制台警告／错误、页面异常、资源请求失败均为 0。

检查包括主题／密度刷新持久化、跨页搜索与空结果、五类组件切换、表单错误与保存、内容筛选／新建／发布同步、移动预约、概览三场景，以及 Spin／Skeleton／Button 和品牌实验的暂停。另确认 5 个抽屉在进入动画未完成时立即 Escape，焦点仍正确归还。此结果来自桌面 Chromium 自动化与内置浏览器检查，未替代真实移动设备、屏幕阅读器和跨浏览器验收。

代表截图：[桌面概览](redesign-assets/overview-desktop.png)、[手机概览](redesign-assets/overview-mobile.png)、[深色组件](redesign-assets/components-dark.png)。它们来自实际 Chromium 渲染，文件中记录了捕获来源。

独立收尾审阅结论为 **ship**：审阅者逐张检查 8 路由桌面／手机的 16 张截图，以及深色组件、紧凑场景、320px 动效和 1264px 概览共 4 张补充截图，并核对最终行为记录与相关源码，未列出 P1／P2 实质问题。该结论覆盖所提交的视觉证据与行为记录，不扩展为全平台认证。

## 实现边界

交付包含 Web 规范、可交互 React 预览、主题配置、CSS/JSON 快照和可复制参考资源。业务数据保存在当前页面，无业务后端；原生 APP、小程序组件、平台转换器、Figma 文件和独立 npm 组件库尚未提供。旧 CSS 别名与历史动效资源用于兼容，不作为新的规范来源。
